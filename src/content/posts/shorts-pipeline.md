재미있는 글을 짧은 영상으로 만드는 일을 자동화해 봤다. 다 자동으로 하면 결과물이 별로였다. 그래서 고르는 단계 하나만 사람이 한다.

## 흐름

1. **큐레이션**: 인기글을 모아 쇼츠에 맞는지 루브릭으로 점수를 매긴다
2. **컨펌**: 어드민 페이지에서 사람이 고른다. 새 후보가 생기면 텔레그램으로 알림이 온다
3. **렌더링**: 워커가 승인된 글을 대본, TTS, 자막을 붙여 mp4 로 만든다

글마다 상태(enum)를 두고 상태 머신으로 다룬다. 단계는 CLI 로도 따로 돌릴 수 있다.

## 해 보니

- 장면 길이는 TTS 길이에 맞춰야 자막이 끊기지 않았다
- 대본은 구어체와 반전이 들어가야 끝까지 봤다
- 밈 이미지는 임베딩으로 검색해서 문맥에 맞는 걸 붙였다

API 는 FastAPI 로 만들었다.
