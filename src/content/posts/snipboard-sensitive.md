클립보드 기록 앱은 복사한 걸 전부 저장한다. 토큰이나 비밀번호까지 남는다는 게 늘 마음에 걸렸다.

## 1. 남이 붙인 표시를 따른다

비밀번호 관리자는 복사할 때 `org.nspasteboard.ConcealedType` 같은 타입을 함께 올린다. 이런 항목은 기록하지 않는다.

```swift
.init("org.nspasteboard.ConcealedType"),
.init("org.nspasteboard.TransientType"),
.init("org.nspasteboard.AutoGeneratedType"),
```

## 2. 생긴 걸 보고 거른다

표시가 없어도 생긴 게 뻔한 값들이 있다. AWS 키(`AKIA…`), GitHub 토큰(`ghp_…`), Slack 토큰, JWT, 개인 키 헤더, `sk-` 로 시작하는 API 키 같은 것들이다. 규칙은 이름과 정규식의 짝으로 두고, 처음 걸린 규칙의 이름을 돌려준다.

```swift
public static func match(_ text: String) -> String? {
    guard text.count <= 100_000 else { return nil }
    ...
}
```

아주 긴 텍스트는 검사하지 않는다. 로그를 통째로 복사할 때 앱이 멈추지 않게 하려는 것이다. 완벽한 방어는 아니다. 그래도 실수로 남는 일은 꽤 줄었다.
